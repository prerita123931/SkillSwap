# SkillSwap 🔄

SkillSwap is a skill-exchange platform that helps students connect with each other to **teach and learn skills**.

## 🚀 Features

- User Registration and Login
- Profile Management
- Add Teaching and Learning Skills
- Skill-based Matching
- Search and Filter Matches
- Send Connection Requests
- User Dashboard
- Admin Dashboard
- MySQL Database Integration

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
